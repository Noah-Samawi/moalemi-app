# Project Summary
The project "معلمي" (My Teacher) is an online tutoring marketplace focused on providing education in Quran, Arabic language, and Islamic studies. It connects students with qualified teachers through a user-friendly interface tailored for Arabic-speaking users, featuring an RTL layout and an aesthetically pleasing design inspired by Islamic culture. Recent enhancements have improved internationalization support, allowing for Arabic and German language options.

# Project Module Description
The application consists of several key modules:
- **Navbar**: Navigation links and search functionality, now includes a language switcher.
- **Hero Section**: Displays promotional content and call to action.
- **Category Filter**: Filters available teachers by category.
- **Teacher Card**: Displays individual teacher details.
- **Teacher Profile Booking**: Facilitates booking sessions with teachers and includes a booking confirmation toast.
- **Dashboard**: User-specific information and upcoming lessons, now with a sidebar for enhanced navigation.
- **Login/Register Modal**: A dialog for user authentication with tabs for login and registration.

# Technology Stack
- **Frontend**: React, Next.js (App Router), Tailwind CSS, Shadcn UI, Lucide-react
- **State Management**: React Query
- **Routing**: React Router
- **Styling**: Tailwind CSS
- **Internationalization**: LanguageContext for AR/DE support

# Usage
1. **Install Dependencies**: Run the following command in the project directory:
   ```bash
   pnpm install
   ```
2. **Build the Project**: To build the project, run:
   ```bash
   pnpm run build
   ```
3. **Run the Development Server**: Start the development server with:
   ```bash
   pnpm run dev
   ```
