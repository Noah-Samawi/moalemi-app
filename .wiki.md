# Project Summary
The project "معلمي" (My Teacher) is an online tutoring marketplace that connects students with qualified teachers specializing in Quran, Arabic language, and Islamic studies. Designed for Arabic-speaking users, it features a user-friendly interface with an RTL layout and an aesthetic inspired by Islamic culture. Recent updates have enhanced internationalization support, allowing for both Arabic and German language options.

# Project Module Description
The application consists of several key modules:
- **Navbar**: Navigation links, search functionality, and a language switcher.
- **Hero Section**: Displays promotional content and a call to action.
- **Category Filter**: Filters available teachers by category.
- **Teacher Card**: Displays individual teacher details.
- **Teacher Profile Booking**: Facilitates booking sessions with teachers and includes a booking confirmation toast.
- **Dashboard**: User-specific information and upcoming lessons, featuring a sidebar for enhanced navigation.
- **Login/Register Modal**: A dialog for user authentication with tabs for login and registration.

# Technology Stack
- **Frontend**: React, Vite, Tailwind CSS, Shadcn UI
- **State Management**: React Query
- **Routing**: React Router v6
- **Internationalization**: LanguageContext for AR/DE support

# Usage
1. **Install Dependencies**: Run the following command in the project directory:
   ```bash
   npm install
   ```
2. **Build the Project**: To build the project, run:
   ```bash
   npm run build
   ```
3. **Run the Development Server**: Start the development server with:
   ```bash
   npm run dev
   ```
