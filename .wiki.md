# Project Summary
The project "معلمي" (Moallemi) is a trilingual online tutoring marketplace that connects students with qualified teachers specializing in Quran, Arabic language, and Islamic studies. It serves Arabic, English, and German speakers, providing a user-friendly interface with RTL support for Arabic and a design inspired by Islamic culture. The platform features a fully integrated Supabase backend for real-time data management, enhancing user experiences and interactions. Recent updates have improved authentication features and added a review system for teachers.

# Project Module Description
The application consists of several key modules:
- **Navbar**: Navigation links, search functionality, and a language switcher for Arabic, English, and German.
- **Hero Section**: Displays promotional content and a call to action.
- **Featured Teachers Grid**: Showcases featured teachers sorted by their professional status and ratings, fetching data from Supabase.
- **Teacher Card**: Displays individual teacher details.
- **Teacher Profile Booking**: Facilitates booking sessions with teachers and includes a booking confirmation toast, now enhanced with a reviews section.
- **Dashboard**: User-specific information and upcoming lessons, featuring a sidebar for enhanced navigation.
- **Login/Register Modal**: A dialog for user authentication with tabs for login, registration, and a forgot password feature.
- **Admin Dashboard**: Allows admin users to manage teacher approvals, bookings, and announcements, fully integrated with Supabase.
- **Teacher Onboarding**: Enables teachers to create and manage their profiles, saving data to Supabase.
- **Reviews Section**: Displays and collects reviews for teachers, integrated into the teacher profile booking interface.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Shadcn UI
- **State Management**: React Query
- **Routing**: React Router v6
- **Internationalization**: LanguageContext for Arabic, English, and German support
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)

# Usage
1. **Install Dependencies**: Run the following command in the project directory:
   ```bash
   npm install
   ```
2. **Build the Project**: To build the project, run:
   ```bash
   npm run build
   ```
3. **Run the Development Server**: Start the development server with:
   ```bash
   npm run dev
   ```
