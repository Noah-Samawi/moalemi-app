# Project Summary
The project "معلمي" (Moallemi) is a trilingual online tutoring marketplace that connects students with qualified teachers specializing in Quran, Arabic language, and Islamic studies. It serves Arabic, English, and German speakers, offering a user-friendly interface with RTL support for Arabic and a design inspired by Islamic culture. The platform now features complete Supabase backend integration, allowing for real-time data management and enhanced user experiences.

# Project Module Description
The application consists of several key modules:
- **Navbar**: Navigation links, search functionality, and a language switcher for Arabic, English, and German.
- **Hero Section**: Displays promotional content and a call to action.
- **Featured Teachers Grid**: Showcases featured teachers sorted by their professional status and ratings, now fetching data from Supabase.
- **Teacher Card**: Displays individual teacher details.
- **Teacher Profile Booking**: Facilitates booking sessions with teachers and includes a booking confirmation toast.
- **Dashboard**: User-specific information and upcoming lessons, featuring a sidebar for enhanced navigation.
- **Login/Register Modal**: A dialog for user authentication with tabs for login and registration, now integrated with Supabase.
- **Admin Dashboard**: Allows admin users to manage teacher approvals, bookings, and announcements, fully integrated with Supabase.
- **Teacher Onboarding**: Enables teachers to create and manage their profiles, saving data to Supabase.

# File Description Inventory
- `README.md`: Documentation for the project.
- `components/`: Contains reusable UI components.
- `data/`: Mock data files for teachers and services.
- `pages/`: Contains the main pages of the application.
- `services/`: API service implementations for authentication, teachers, bookings, and more.
- `hooks/`: Custom hooks for managing state and fetching data.
- `i18n/`: Includes language context and translation files.
- `config/`: Configuration files for Supabase and other services.
- `docs/`: Contains design documents including system architecture, class diagrams, and ER diagrams.
- `src/lib/supabase.ts`: Supabase client initialization.
- `src/services/authService.ts`: Login, register, logout, session management.
- `src/services/teacherService.ts`: Full CRUD for teachers table.
- `src/services/bookingService.ts`: Booking creation and retrieval.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Shadcn UI
- **State Management**: React Query
- **Routing**: React Router v6
- **Internationalization**: LanguageContext for Arabic, English, and German support
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)

# Usage
1. **Install Dependencies**: Run the following command in the project directory:
   ```bash
   npm install
   ```
2. **Build the Project**: To build the project, run:
   ```bash
   npm run build
   ```
3. **Run the Development Server**: Start the development server with:
   ```bash
   npm run dev
   ```
