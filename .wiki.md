# Project Summary
The project "معلمي" (My Teacher) is an online tutoring marketplace aimed at providing education in Quran, Arabic language, and Islamic studies. The platform connects students with qualified teachers, offering a user-friendly interface designed specifically for Arabic-speaking users. It features a right-to-left (RTL) layout and a visually appealing design inspired by Islamic aesthetics.

# Project Module Description
The application consists of several key modules:
- **Navbar**: Provides navigation links and search functionality.
- **Hero Section**: Displays the main promotional content and call to action.
- **Category Filter**: Allows users to filter available recipes by category.
- **Recipe Card**: Displays individual recipe details.
- **Recipe Detail**: Shows detailed information about a selected recipe.
- **Teacher Profile Booking**: Facilitates booking sessions with teachers.
- **Dashboard**: Displays upcoming lessons and user-specific information.

# Technology Stack
- **Frontend**: React, Next.js (App Router), Tailwind CSS, Shadcn UI, Lucide-react
- **State Management**: React Query
- **Routing**: React Router
- **Styling**: Tailwind CSS

# Usage
1. **Install Dependencies**: Run the following command in the project directory:
   ```bash
   pnpm install
   ```
2. **Build the Project**: To build the project, run:
   ```bash
   pnpm run build
   ```
3. **Run the Development Server**: Start the development server with:
   ```bash
   pnpm run dev
   ```
